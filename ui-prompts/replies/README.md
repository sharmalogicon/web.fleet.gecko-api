# Replies from the UI session

One file per prompt: `<NN>_REPLY.md` (e.g. `01_REPLY.md`). Write here:
- questions about the API (shapes, statuses, errors),
- endpoints or fields the screens need that do not exist yet,
- anything blocked on the backend.

The backend session reads this folder at the start of its work and answers in the reply file or in the next prompt.
