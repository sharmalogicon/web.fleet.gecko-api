You are the UI session for **Gecko Fleet**. Prerequisites: **02** (Fleet Setup tabs), **15** (vendor billing + the export

The API now posts approved vendor invoices and credit notes to **SAP Business One** (Service Layer) and reads the vendor
payments back. SCT's real SAP details are not known yet, so the API has a built-in **simulator**: a connection whose URL starts
with `fake://` (e.g. `fake://demo`) behaves like SAP (documents get a DocEntry / DocNum, payments can be read back). Build and
test the screens against it.

**No new page.** Two additions only: two tabs on the existing `/master/fleet-setup` (§A), and a target choice + SAP status in

## A. Fleet Setup → tabs "ERP connection" and "ERP mappings" (`fleet.setup.manage`, tenant-wide; else hide the tabs)
- `GET /api/fleet/setup/erp-connection` (404 = none yet → empty form) → `{ baseUrl, companyDb, userName, passwordRef,
  passwordSet, defaultSeries, isActive, lastTestAt, lastTestResult, lastPaymentSyncAt, remarks, rowVersion }`.
  `PUT /api/fleet/setup/erp-connection` `{ baseUrl, companyDb, userName, passwordRef?, defaultSeries?, isActive, remarks?, rowVersion? }`.
  **The password is never typed into Fleet**: `passwordRef` is the NAME of a server secret (`Erp:Secrets:<name>`) that IT sets on the
  host. Show `passwordSet` as "Password configured on the server: yes / no" (a fake:// connection needs none). Field help:
  baseUrl = `https://<sap-host>:50000/b1s/v1` or `fake://demo`.
  Button **Test connection** → `POST /api/fleet/setup/erp-connection/test` → `{ ok, message, testedAt }` (show the message green / red).
- `GET /api/fleet/setup/erp-mappings?mapType=` → rows `{ erpMappingId, mapType, geckoCode, erpCode, description }`;
  `PUT /api/fleet/setup/erp-mappings` `{ mapType, geckoCode, erpCode, description? }` (adds or changes the map with that key);
  `DELETE /api/fleet/setup/erp-mappings/{id}`. Group the table by type with these hints:
  | mapType | geckoCode | erpCode |
  |---|---|---|
  | `GL` | one of `GRN_STOCK`, `GRN_SERVICE`, `WO_SUBLET`, `TYRE_EVENT`, `MANUAL`, `CREDIT` (fixed list → a select) | SAP G/L account |
  | `TAX` | VAT rate, e.g. `7` (and `0` if SAP wants a code on zero-rated lines) | SAP purchase tax code |
  | `WHT` | WHT rate, e.g. `3` | SAP WTCode |
  | `BP` | Gecko supplier party code (supplier picker) — only when it differs from the SAP CardCode | SAP CardCode |
  400 errors come back on `geckoCode` (e.g. "TAX / WHT maps are keyed by the rate").

## B. Export dialog (prompt 15 §E) — choose the target
Add a choice **CSV file / SAP Business One** (SAP only when the ERP connection exists and is active — read it once with
`GET /setup/erp-connection` if the user has `fleet.setup.manage`; otherwise just offer both and show the 409 message).
`POST /api/fleet/ap-exports { invoiceIds, creditNoteIds, target: "SAP_B1" }` → the batch `{ batchNo (SAP-…), target, status:
SENT | PARTLY_FAILED | FAILED, invoiceCount, creditNoteCount, errorText, documents[] }`. Each document in `documents` carries
`erpDocNum` (posted) or `erpError` (not posted — it stays APPROVED and appears in "pending" again). Show the per-document result
in the dialog (green DocNum / red error). A missing map gives a clear error, e.g. "No G/L account for MANUAL lines (Setup → ERP
mappings, GL MANUAL)". 409 "No active SAP Business One connection".

## C. Batch history / retry, payments, reconciliation (inside the same dialog or its history view — no new page)
- Batch view `GET /api/fleet/ap-exports/{id}`: for a SAP batch with failures, button **Retry failed** →
  `POST /api/fleet/ap-exports/{id}/retry` (a document SAP already holds is matched, never posted twice). CSV batches keep their download.
- **Pull SAP payments** (`fleet.vendorinvoice.export`) → `POST /api/fleet/erp/payments/pull` (optional `?since=yyyy-MM-dd`) →
  `{ paymentsRead, rowsRecorded, invoicesPaid, unmatched[], syncedAt }`. Recorded payments appear in `/invoice/vendor-payments`
  with `source` ERP (show a small "SAP" badge there; ERP rows cannot be reversed in Fleet).
- **Reconcile with SAP** → `GET /api/fleet/erp/reconciliation?from=&to=` → rows `{ docType, documentNo, supplierDocNo, supplierPartyCode,
  erpDocNum, geckoTotal, sapTotal, geckoPaid, sapPaid, result }` with `result` OK / TOTAL_DIFFERS / PAID_DIFFERS / MISSING_IN_SAP
  (tolerance 1.00: SAP rounds VAT per line). A read-only table; colour the non-OK rows.
- Vendor invoice / credit note forms: show `erpDocNum` (and `erpError` in red when set) read-only next to the status.
